<td valign="top">

### 🩺 CareFlow — Real-Time Healthcare Analytics

An end-to-end healthcare data engineering platform. Synthetic patient data flows through a validated medallion pipeline into a dimensional PostgreSQL warehouse, is modeled and tested with dbt, orchestrated with Airflow, and delivered through a live interactive dashboard.

**Stack:** `Python` · `PostgreSQL` · `dbt` · `Apache Airflow` · `Streamlit`

```
Synthetic healthcare data
        ↓
     Bronze
        ↓
     Silver
        ↓
      Gold
        ↓
Dimensional PostgreSQL warehouse
        ↓
   dbt models / tests
        ↓
 Airflow orchestration
        ↓
 Streamlit analytics
```
