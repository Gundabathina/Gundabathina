## `> whoami`

Data Engineer focused on building reliable, well-tested data platforms — from ingestion and transformation through orchestration and analytics delivery.

I build the data platforms that turn raw, messy source systems into trustworthy, analytics-ready products. My work spans the full data engineering lifecycle: ingestion, layered transformation (Bronze/Silver/Gold), dimensional warehouse modeling, governed analytics engineering with dbt, and orchestration with Airflow — with automated testing and data-quality checks built in at every layer, not bolted on after the fact.

## `> featured-project`

<details open>
<summary><b>&#9654;&nbsp; CareFlow — Real-Time Healthcare Analytics</b></summary>

<br/>

An end-to-end healthcare data engineering and analytics platform using Python, PostgreSQL, dbt, Apache Airflow, and Streamlit. Synthetic patient data flows through a validated Bronze/Silver/Gold pipeline into a dimensional PostgreSQL warehouse, is modeled and tested with dbt, orchestrated end-to-end with Airflow, and delivered through a live interactive dashboard.
